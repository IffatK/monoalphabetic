Computer Networks — Cryptography Module

Two ways to turn PLAINTEXT into ciphertext.

This project explores symmetric encryption from two angles — a stream cipher that encrypts data bit by bit as it flows, and a block cipher that encrypts data in fixed-size chunks. Pick a track below to open the live demo.

Stream Cipher

Continuous keystream XORed against data one bit or byte at a time — fast, low-latency, built for streaming data.
